# Default blocks

<!-- cspell:ignore loginout nextpage uamswp -->

Written against v1.3.1.

These blocks are removed when the plugin is activated, until the list is first saved, and again after *Reset to Defaults*. They come from `uamswp_block_remover_default_blocks()` in [`uamswp-block-remover.php`](https://github.com/UAMS-Web/uamswp-block-remover/blob/main/uamswp-block-remover.php). To keep one of them, uncheck it on the settings page and save; see [Settings](Settings.md).
